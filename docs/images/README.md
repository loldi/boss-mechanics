| File | What to capture |
|---|---|
| `hero.gif` | Collection log open on a supported boss, click Boss Mechanics, window opens, click through 2-3 mechanics with previews playing |
| `discovery.gif` | A `???` row unlocking mid-fight: row fills in, chat message appears, progress bar ticks up |
| `move-list.png` | Move list on the left, selected mechanic's description and counterplay on the right, mix of discovered and `???` rows |
| `previews.gif` | 3-4 previews in a row, ideally including a chained animation (Doom's Shockwave) and a static/idle one |
| `drag.gif` | Dragging the window by its title bar, grey outline visible mid-drag, full window back at drop |

Keep gifs under ~5 MB so they load on the GitHub page.
